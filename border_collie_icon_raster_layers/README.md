# Border Collie Prompt Icon — Raster Layers

These layers were extracted from the generated icon and kept on the same transparent canvas.

Import order / depth order for Apple Icon Composer:

1. `01_front_eyes_nose.png` — front: prompt `>` eye, `_` eye/cursor, and `-`/minus-style nose.
2. `02_white_muzzle.png` — white blaze / white part surrounding the nose.
3. `03_black_face_solid_ears.png` — black face and ears. The original white ear inserts were removed and filled as black ear area.
4. `04_white_beard.png` — bottom white beard / cheek fur.

Files:
- `*.png`: 1024 x 1024 transparent PNGs.
- `*@2x.png`: 2048 x 2048 transparent PNGs.
- `*_source1254.png`: source-resolution transparent PNGs from the generated image.
- `preview_dark_solid_ears.png`: preview on dark background.
- `composite_transparent.png`: final transparent composite.

Note: because the source icon was a raster image, the separated layers are raster masks rather than fully editable vector paths.
